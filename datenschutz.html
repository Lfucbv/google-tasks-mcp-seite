Privacy policy

Last updated: 21 October 2026

Tasks MCP is a personal tool of Nils Loewen. It is used only by its developer with his own Google account.

Data accessed

With the user's consent the app accesses the user's Google Tasks (scope https://www.googleapis.com/auth/tasks): task lists and tasks, including titles, notes and due dates.

How data is used

The data is read and changed only on the user's request, by an AI assistant running on the user's own computer. It is not sold, shared, published or used for advertising, and it is not transferred to the developer or any third party by this app.

Storage

The app stores only an OAuth token in a file on the user's own computer. It keeps no database and no copy of the tasks. Access can be revoked at any time at myaccount.google.com/permissions.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
