Tasks MCP

Tasks MCP is a small personal tool that lets an AI assistant (Claude Code) read and edit the Google Tasks lists of its owner, Nils Loewen. It runs only on the owner's own computer and is not offered to other users.

It requests a single permission, access to Google Tasks, and uses it only to list, create, update, complete and delete tasks on the owner's request. Nothing is sent to any server operated by the developer.
